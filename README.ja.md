# cat-smf-editor

SMF(Standard MIDI File)を手軽に編集できることを目指している軽量アプリ。[UAPMD](https://github.com/atsushieno/uapmd)を利用しています。Rustで書かれています。

編集機能にクセがあります。ほぼ自分専用です。明日には仕様変更して今までのファイルが読めなくなる可能性があります

## これまでの課題と、このアプリが解決すること
### SMF編集
- [The Mutopia Project](https://www.mutopiaproject.org/) のように、CC0ライセンスの音楽データを公開する試みは、素晴らしいですね！
- 本格的な演奏や、そのための編集には、DAWを起動するなど、前準備が必要なことが多いです。
- 手軽に演奏や編集するための軽量アプリは、操作感覚がnot for meだったりしました。
- 現代は、ほしいUXがあれば、バイブコーディングで実現できます。
- そうすることにしました。
### 気楽に簡易な作曲っぽい遊びを楽しむ
- 現行のSMFエディタやDAWは、自分のほしいワークフローの実現にはnot for meだったりしました。
- 現代は、ほしいUXがあれば、バイブコーディングで実現できます。
- そうすることにしました。

## コンセプト、目指すもの
- おもちゃ
  - エディタよりはおもちゃを目指します
  - このアプリの位置づけは [おもちゃ] >> 教育用 >> 商業用 くらいのイメージです
  - editできるのはごくわずかな要素だけです
  - 名前にeditorが入っていますが気にしない
- 鳴ること
  - 「作者の環境で鳴ること」はできるだけ維持することを目指します
- すぐ鳴ること
  - アプリ起動から音が鳴るまで1trackなら体感0.2秒。演奏までを最速にしています
    - GUI表示準備などの処理も、音の後にしています
      - GUI表示より先に音が鳴るのは、いわばスプラッシュスクリーンのサウンド版かもしれません
- 自分が使うワークフローだけを実装する
  - 開発リソースがほぼゼロのため、トリアージです
  - この種のエディタの開発には膨大な開発コストが必須です
    - 例えば、アンドゥやタイムマシンや非破壊編集など、安全な編集とスタンダードなUXを両立するため、データモデル設計に運用設計に洗い出しに検証用実装とドッグフーディングなどをディレクションして機能を取捨選択（はスタンダードを目指すとできないので全部入りにするしかない）、などだけでも開発コストが膨大です
  - もし、よくありそうな「軽量でスタンダードなエディタ」をお探しなら、ほかをあたってください
- 教育用から実験用へ
  - 商業用よりは、教育用の方向を向いています
  - が、このアプリは上記の制約のため、
  - 教育用よりも、おもちゃ or 実験用 の方向を向いています
- 実験、探索、自分用
  - 頻繁に破壊的変更をします
    - 昨日saveしたファイルが今日loadできないのは日常茶飯時となります
      - なので利用はおもちゃレベルにとどめてください

## 思ったことを雑に書くコーナー
- SMFエディタは、いろいろな用途があり、考慮ポイントが多すぎ、「実用になるレベルを目指すと」開発コストが膨大すぎる
  - おもちゃ。一部だけ、がっつり編集したい。音色とエフェクト、テンポカーブ、アルペジオ、ピアノロールで各noteを微調整。素早く編集と検証のサイクルをまわすことを優先し、loadやsaveは手動操作なしの全自動 → 当アプリのターゲットとするワークフローが、そのごく一部
  - サクサクとブラウズ演奏したい、サクサク中身を可視化したい。軽量のブラウザやビューア
  - ちょっと変更したい。変更部分以外は完全に元のままであることを担保、そのためのdiff可視化。軽量のエディタ
  - 作編曲の練習用おもちゃ
    - カジュアルな可視化、カジュアルな編集。混乱防止のため非破壊編集もあるとよいが開発コストは膨大になる
    - いや、SMFエディタじゃなく、スタンダードなモダンな他のアプリで作曲したほうがいいと思います
  - 本格的な作編曲
    - 上に同じ
    - さらに、高度なアンドゥ、タイムマシン、非破壊編集などを極めて高水準に実現が必須
- 今後追記予定

## スコープ外、目指さないもの
- DAW
  - SMFだけでなくDAW projectほか有名DAWのprojectを直接読み書きし、編集可能、もちろんAudioも
- プラグイン
  - あらゆるエディタ機能を自由にプラグインで拡張
- script
  - あらゆるエディタ機能を自由にscriptで拡張
- スタンダード
  - 標準的なSMFエディタやDAWの見た目や挙動を200%網羅。すべてのエディタとDAWに対して完全上位互換
- 機能
  - あらゆる機能を搭載。あらゆる用途で利用可
- 互換性
  - データの完全互換
    - あらゆるSMFをload可能、あらゆるDAWのprojectをimport可能
    - exportはあらゆる音楽データ、あらゆるDAWのprojectに対応
  - 設定の完全互換。あらゆる過去の設定をloadして動作する
- 堅牢さ
  - 何をしても絶対にバグらない。アプリが落ちない
- 利便性
  - 便利さ、使いやすさを極限まで追求
- 性能
  - あらゆる環境でCPU負荷なく高速に動作。音は絶対に途切れない
- 要望
  - ユーザーのあらゆる要望に即応
