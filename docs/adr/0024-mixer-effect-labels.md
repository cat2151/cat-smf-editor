# ADR 0024: ミキサーのエフェクト欄で識別に必要な名前を優先する

- 状態: 採用
- 決定者: user（Surge XT Effects は種類を、TONE3000 は製品名を優先し、付随情報も収まる分だけ表示する）
- 関連: [0007: effect chain](0007-effect-chain-on-uapmd-graph.md)

## 理由と決定

ミキサーは、エフェクトチェーンの各スロットを一覧で見分けられるよう、プリセットの表示名をそのまま使っていた。Surge XT Effects は複数の種類を一つのプラグインで提供するため、製品名が幅を占めると「surge xt: del」のように種類が途中で切れると user から報告があった。一方、TONE3000 では、モデルごとに異なるプリセット名より製品名で判別したいという要望があった。

種類や製品名だけを欄に出す方式では、同じ種類や製品を使ったスロットのプリセットを一覧で見分けにくい。実画面を確認した user は、最優先の情報が先頭で読めれば、付随情報の末尾は省略されてよいと明示した。

トラックとマスターのミキサー欄では、Surge XT Effects はプリセットの最上位フォルダ名（例: `Delay`）を先頭に置き、その後にプリセット名と製品名を続ける。TONE3000 は製品名にモデルのプリセット名を続ける。トラック欄は先頭からセル幅に収まる分を表示し、ツールチップには元の表示名を残す。
